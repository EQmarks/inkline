# 抄写台

> 逐行标记，抄到哪行心里有数。

把要抄写的文字粘进来，抄完一行点一下：当前行始终高亮，已抄的行变淡并打勾。手抄长文时再也不用盯着纸面反复找行、生怕写串。

手机、电脑都能用，断网也能用（PWA），数据只存在本机浏览器。

![桌面端抄写界面](docs/reader-desktop.png)

## 它解决什么问题

抄长段落时最容易出的错是「写串」——眼睛在纸面和屏幕之间重新找位置，一不留神就跳行、重行。抄写台让「当前行」始终唯一且醒目：

- **未抄完的第一行 = 当前行**：暖色底 + 左侧朱砂条，一眼可见
- **已抄的行自动变淡打勾**：扫一眼就知道抄到哪了
- **聚焦模式**：离当前行较远的行继续变淡，视线不容易被带跑
- **进度条 + 已抄/总行数**：常驻顶部，心中始终有数

## 功能

- **录入**：粘贴文本、导入 txt / md 文件、填入示例；支持「按行」或「按句」自动拆分
- **逐行标记**：点任意一行切换「已抄 / 未抄」，或按空格完成当前行
- **防写串**：当前行高亮、聚焦变淡、可隐藏已抄的行、完成后自动滚动到下一行
- **本地保存**：内容、进度、显示设置自动写进浏览器 localStorage，关掉页面也不丢，下次打开点「继续」
- **显示设置**：字号 15–30px、行距、楷体 / 宋体 / 黑体、浅色 / 深色 / 跟随系统
- **键盘操作**：空格完成、Backspace 撤销、E 回编辑、+ - 调字号
- **手机友好**：大触控区域、底部悬浮操作栏、刘海屏安全区适配、无横向滚动
- **离线可用**：Service Worker 缓存全部资源，可添加到主屏幕当 App 用
- **可直接打印**：打印时会隐藏操作界面，只留抄写内容

## 使用方法

1. 打开页面，把要抄的内容粘贴进输入框（每段一行），或点「导入 txt / md 文件」
2. 需要的话切换「按句」：长段落会按 。！？； 自动切成短行
3. 点「开始抄写」
4. 抄完一行就点那一行，或点底部「完成本行」：
   - 手机上：点行最方便，单手也能操作
   - 电脑上：按空格完成当前行，Backspace 撤销
5. 关掉页面也没关系，进度自动保存；下次打开点「继续」

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 / Enter | 完成当前行 |
| Backspace / Z | 撤销上一步 |
| E | 回到编辑 |
| + / - | 调整字号 |
| Ctrl / ⌘ + Enter（录入页） | 直接开始抄写 |

## 数据与隐私

所有内容只写在本机浏览器的 localStorage（键名 chaoxie:v1），不上传、不经过任何服务器。因此换设备或换浏览器不会同步；清理浏览器数据会一并清空。

## 本地运行

纯静态站点，无需构建、无依赖：

    python -m http.server 8000
    # 或
    npx serve .

然后打开 http://localhost:8000 。直接双击 index.html 也能用，只是没有离线缓存（Service Worker 需要 http/https）。

## 部署到 GitHub Pages

仓库已按 Pages 组织（全部相对路径 + .nojekyll）：

1. 仓库 **Settings → Pages**
2. **Source** 选 Deploy from a branch，分支 main，目录 / (root)
3. 保存后访问 https://<用户名>.github.io/<仓库名>/
