# 抄写台 InkLine

> 点哪句，从哪句开始抄。

把要抄的整段文字粘进来，自动切成一句一行。抄的时候点任意一句，就从那句开始往下抄：**当前句黄色高亮，抄过的句子变灰**，进度按顺序推进——不用记录每句抄没抄，也不会写串。

手机、电脑都能用，断网也能用（PWA），内容只存在本机浏览器。

**在线使用：<https://eqmarks.github.io/inkline/>**（GitHub Pages）

![桌面端抄写界面](docs/reader-desktop.png)

## 怎么防写串

手抄长文时最怕「写串」：抬头看屏幕、低头写字，一不留神就跳行、重行。抄写台用**线性进度**解决：

- **自动分句**：粘贴整段文字，自动切句，每句一行；长句会在分号、逗号处再拆短
- **点哪句从哪句抄**：点一下某句，它变成当前句，它前面的句子自动算作已抄（变灰）
- **当前句唯一高亮**：黄色底 + 黄色竖条 + 绿色序号，一眼锁定
- **进度按顺序**：顶栏「第 3 / 24 句」+ 进度条；下一句 / 上一句 / 空格键依次推进
- **聚焦模式**：离当前句较远的句子自动变淡，视线不被带跑

没有勾选、没有撤销某句已抄——就是一条线，抄到哪算哪。

## 功能

- **录入**：粘贴整段文字、导入 txt / md 文件、填入示例
- **智能分句**：按 。！？ 等句末标点切分，引号、括号跟随前句；超过 42 字的长句在分号、逗号处拆短
- **线性抄写**：点任意一句定位；底部「上一句 / 下一句」或空格、方向键推进
- **进度保存**：内容和位置自动存进浏览器 localStorage，关掉再开点「继续」，从上次那句接着抄
- **显示设置**：字号 15–30px、行距、楷体 / 宋体 / 黑体、浅色 / 深色 / 跟随系统、显示序号、自动滚动
- **手机友好**：大触控区域、底部悬浮操作栏、刘海屏安全区适配、无横向滚动
- **离线可用**：Service Worker 缓存全部资源，可添加到主屏幕当 App 用
- **可直接打印**：打印时隐藏操作界面，只留抄写内容

## 配色

绿（主色）/ 黄（当前句）/ 灰（已抄、次要信息），浅色深色各一套。

## 使用方法

1. 打开页面，把要抄的内容整段粘贴进输入框（不用自己分行），或点「导入 txt / md 文件」
2. 点「开始抄写」，自动分句
3. 点任意一句，就从那句开始抄；抄完一句点「下一句」或按空格
4. 关掉页面也没关系，进度自动保存；下次打开点「继续」

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 / Enter / → | 下一句 |
| Backspace / ← | 上一句 |
| E | 回到编辑 |
| + / - | 调整字号 |
| Ctrl / ⌘ + Enter（录入页） | 直接开始抄写 |

## 数据与隐私

所有内容只写在本机浏览器的 <code>localStorage</code>（键名 <code>inkline:v1</code>），不上传、不经过任何服务器。换设备或换浏览器不会同步；清理浏览器数据会一并清空。

## 本地运行

纯静态站点，无需构建、无依赖：

~~~bash
python -m http.server 8000
# 或
npx serve .
~~~

然后打开 http://localhost:8000 。直接双击 <code>index.html</code> 也能用，只是没有离线缓存（Service Worker 需要 http/https）。

## 部署到 GitHub Pages

仓库已按 Pages 组织（全部相对路径 + <code>.nojekyll</code>）：

1. 仓库 **Settings → Pages**
2. **Source** 选 Deploy from a branch，分支 <code>main</code>，目录 <code>/ (root)</code>
3. 访问 https://eqmarks.github.io/inkline/
